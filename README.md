# ColorDuo

为 ColorOS 系统桌面的「倾斜」翻页添加景深效果：近处清晰，远处虚化。

[下载稳定版](https://github.com/daxiaamu/ColorDuo/releases/latest) · [查看预发布版](https://github.com/daxiaamu/ColorDuo/releases)

- **效果1 · 高斯景深**：柔和渐进虚化。
- **效果2 · 磨砂雾化**：细颗粒雾化，默认效果。

## 使用方法

1. 安装 APK，在 LSPosed 中启用 ColorDuo。
2. 作用域仅勾选系统桌面（`com.android.launcher`）。
3. 重启系统桌面或手机。
4. 将桌面的「翻页效果」设置为「倾斜」。
5. 打开 ColorDuo 选择效果1或效果2，返回桌面翻页即可体验。

设置页支持检查更新；打开应用后也会自动检查，可选择接收预发布版本。下载完成后按系统提示允许安装。

**切换效果实时生效、自动保存，无需重启桌面。** 首次安装或升级模块后，仍需重启一次桌面或手机。

已验证：ColorOS 16 / Android 16，系统桌面 16.6.17。ColorOS 17 桌面 17.3.9 已完成静态适配，待真机验证（[适配说明](docs/coloros17-compatibility.md)）。

如需停用，在 LSPosed 中禁用模块并重启桌面；出现异常时无需清除桌面数据。
